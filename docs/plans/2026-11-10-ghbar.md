# Plan: ghbar

> **Spec:** docs/specs/ghbar/SPEC.md

**Lessons applied:** none
**Goal:** A Noctalia v5 plugin that shows the unread GitHub notification count in the bar and the inbox in a panel, built on the scaffold harness.
**Depends on:** none
**Architecture:** `service.luau` is the only entry that runs `gh`, calls HTTP, opens URLs and notifies; it publishes one `view` on `noctalia.state`. `widget.luau` and `panel.luau` only render that view and send commands (`cmd.refresh`, `cmd.open`). Decisions live in pure `lib/` modules (`gh`, `notifications`, `poll`, `view`).
**Tech Stack:** Luau, Noctalia v5 plugin API 22, scaffold test harness (`./run-tests`, mocked host), GitHub REST `/notifications`.
**Total Tasks:** 12
**Estimated Complexity:** large

---

## Global rules for every task

- TDD for logic: write the Luau test, run it and see it fail, implement, run it green, then the full suite `./run-tests`. Read the `N passed, M failed` line, never a piped exit code. Single file: `./run-tests tests/<name>.test.luau`.
- `lib/*.luau` is pure: no `noctalia`, `barWidget`, `panel`, `ui` globals. Modules return one table and require siblings as `require("./x.luau")`. Tests load them with `modules.load("lib/x.luau")`; entries with `entry.load("service.luau", opts)`.
- The mock records `noctalia.http` calls as `{ request, callback }`; tests invoke the callback by hand with `{ ok = true, status = 200, body = "..." }`. `runAsync` with a callback needs a scripted `async = { [key] = AsyncResult }` answer; the key is the argv joined by spaces.
- The host `http` response carries only `ok`, `status`, `body` (no headers), so there are no conditional requests.
- The token lives only in a local of the poll callback and in the `headers` list of `noctalia.http`. Never in `noctalia.state`, logs, files, argv or notifications. Tests use the fake token `SECRET-GH` and assert it never appears in any recorded state, log or notify call.
- Colors are theme tokens only (`on_surface`, `on_surface_variant`, `primary`, `error`, alpha suffixes such as `surface/0.5`); no hex. Emit every visual property on every render.
- Fixtures use fake data (`octo/hello`, ids `1001..`) and no `/home/<user>` path.
- UI strings go through `noctalia.tr`; `translations/en.json` and `translations/pt-BR.json` stay in sync.
- English code and comments. No git commands inside tasks except the per-task `/git commit`.
